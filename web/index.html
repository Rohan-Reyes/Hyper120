Why it matters

Twice the frames. You can feel it.

Each ghost is one frame your screen actually shows. At 60Hz a fast swipe jumps 16.7 ms at a time; at 120Hz it moves in 8.3 ms steps, with half the input lag.

How it works

It uses Xiaomi's own switch.

PowerKeeper, the system service that caps your games, already listens for a "this game may run faster" message from Xiaomi's game service. Hyper120 sends that same message for the games you pick.

01 · YOU

Pick games & a rate

Games are ticked automatically. Choose 90, 120 or 144Hz.

02 · HYPER120

Sends the override

One broadcast per game, repeated every 15 s while the screen is on.

03 · POWERKEEPER

Adds it to the allow-list

The game moves into mPrivGames and is no longer capped.

04 · DISPLAY

Switches to 120Hz

Only while that game is open. Everything else stays adaptive.

# the broadcast Hyper120 sends (no root required) action com.xiaomi.joyose.OVERRIDE_GAME_FRESHRATE package com.miui.powerkeeper extras override_pkg_name = "com.mobile.legends" override_freshrate = 120

Features

Set it once. It keeps working.

Per-game refresh rate

Rates come from your panel: 60, 90, 120 or 144Hz. Only the apps you tick get them.

No battery trade-off

PowerKeeper and adaptive refresh stay on, so your home screen and apps still drop to save power.

Auto-adds new games

Install a game and it's unlocked straight away. Untick one and it stays unticked.

Built-in FPS tester

Tests 60, 90 and 120Hz on your own phone and tells you which ones work.

Rate per game + widget

Long-press a game to give it its own rate, like 120 for MLBB and 90 for Free Fire. Long-press your home screen → Widgets → Hyper120 to add a widget that switches rates in one tap (on HyperOS, allow the Home screen shortcuts permission first).

One-tap game reports

Tell us if a game hit 120. The report fills in the game, your phone, ROM and region. The game list updates in the app daily.

Install

Under a minute, on the phone.

  1. Download the APKIf your phone warns that the app isn't safe, tap More details → Install anyway (see FAQ). Get Hyper120.apk from here or GitHub Releases and open it. Allow installs from unknown sources if asked.
  2. Open Hyper120Your games are found and set to your screen's top rate straight away.
  3. Set your phone to 120HzSettings → Display → Refresh rate → 120Hz (High). Games can't go faster than this, and Hyper120 warns you if it's on 60Hz.
  4. Let it run in the backgroundIn About → Open App info, turn on Autostart and set Battery saver to No restrictions.
  5. Check it workedTap the gauge icon to open the FPS tester. You should see "120 Hz works".

Still 60? Check the game.

Hyper120 removes the phone's 60Hz cap. Every game also has its own limit, and Hyper120 can't go past it. If a game stops at 60, the screen will happily run at 120, but the game only draws 60 new frames.

FAQ

Questions

It works in the tester, but my game still runs at 60. Why?

Because the game has its own limit. Hyper120 lifts the phone's cap, which the FPS tester proves, but some games are built to stop at 60 on Android (Roblox, Genshin Impact, Honkai: Star Rail and others). Check the game list. If your game is in the 60 max column, no app can push it higher without modding the game.

Which popular games are stuck at 60?

Roblox, Genshin Impact, Honkai: Star Rail, Zenless Zone Zero, Wuthering Waves, Pokémon UNITE, PPSSPP (PSP games), Bus Simulator Indonesia, Truckers of Europe 3, eFootball, Monster Hunter Now and Archero 2. These games limit themselves, so they stay at 60 even with Hyper120 on. The app tags them 60 MAX. See the full game list.

Which games can go above 60?

Mobile Legends: Bang Bang, Call of Duty: Mobile, PUBG Mobile / BGMI, Honor of Kings, League of Legends: Wild Rift, Delta Force, Standoff 2, Brawl Stars, Clash of Clans, Minecraft, Asphalt Legends, CSR 2, Top Drives, Pokémon GO, EA SPORTS FC Mobile, World of Tanks Blitz, Block Blast!, Spaceflight Simulator, 8 Ball Pool, Subway Surfers, Shadow Fight 2, Shadow Fight 3, Shadowgun Legends, Dead Trigger 2, Pixel Gun 3D, Plants vs Zombies 2, Soul Knight, Hill Climb Racing 2, Temple Run 2, Sonic Dash, Marvel Contest of Champions, Mortal Kombat, Injustice 2, Summoners War, Toon Blast, Tank Stars, Stick War: Legacy, Traffic Rider, Bullet Force, Mini Metro, Alto's Odyssey, Grimvalor, Super Mario Run, Dragon Ball Legends and Old School RuneScape can, but you must turn on the high frame rate in each game's settings, and many only show it on phones the developer has approved. Free Fire / Free Fire MAX and Fortnite top out at 90.

My game isn't on the list. How do I know?

Look in the game's graphics settings for a frame-rate option. If the highest choice is 60 (or there's no option at all), the game is most likely capped at 60. Then check with Game Turbo's FPS counter while playing, long-press the game in Hyper120 and tap Report how it runs. We'll add it to the list.

My game has no 120 FPS option. Can Hyper120 add it?

No. Games like Mobile Legends, PUBG Mobile and Call of Duty: Mobile decide which phones see their 90/120 option. If your phone isn't on the developer's list, the option stays hidden. Hyper120 makes sure the screen isn't the bottleneck once the game asks for more.

How do I see a game's real FPS?

Use the FPS counter in Game Turbo (swipe in from the edge while in a game and turn on the performance overlay). Developer options → "Show refresh rate" shows the screen rate, not the game's. In a 60-capped game it can say 120 while the game still draws 60.

Which rate should I pick, 90 or 120?

Pick the highest your game supports. If a game tops out at 90, choosing 120 does no harm; the game just draws 90. Picking 60 sends games back to normal.

My phone says the app isn't safe or won't install it.

Hyper120 isn't on the Play Store, so your phone warns about it like any downloaded app. On Play Protect, tap More details → Install anyway (you may need your fingerprint or PIN). On Xiaomi's security scan, tap Continue installation. If it says "App not installed", uninstall any old copy first. Since v4.2.1 it's signed with a proper release key and asks for fewer permissions, which avoids most warnings. The source code is public on GitHub, and every release lists the APK checksum so you can check your download.

How do I turn 120Hz off for a game?

Untick the game in the list. PowerKeeper remembers the last value until it restarts, so to switch back right away, pick 60 and tap Apply, or reboot. To stop everything, turn off Background override or uninstall the app.

Does it drain my battery?

Only games you tick run faster, and only while they're open. PowerKeeper and adaptive refresh stay on, so the rest of the phone behaves exactly as before. The background service wakes for a moment every 15 seconds while the screen is on and sleeps while it's off.

The tester says "Clamped". What now?

First check Settings → Display → Refresh rate is set to 120Hz (High). On 60Hz (Standard) nothing can go higher; this fixed it on a Xiaomi 17. Then tap Re-apply, and make sure Autostart is on and Battery saver is set to No restrictions. If it still clamps, please tap Report so we can look into your ROM.

Is it safe? Does it need root or special permissions?

No root, no ADB, no accessibility service. It sends the same broadcast Xiaomi's game service (Joyose) uses. The code is open on GitHub.

Does it collect data?

No account, ads or analytics. Every 12 hours it sends a random ID (no device info) so I can count active installs.
