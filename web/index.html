Quick Setup

Install directly on your phone in under 60 seconds.

Option A: Direct APK Install (Recommended)

  1. Download Hyper120.apk from GitHub Releases.
  2. Open the downloaded APK and allow Install from unknown sources if prompted.
  3. Launch Hyper120 — your installed games are detected and unlocked automatically.
  4. Long-press Hyper120 → App info and set Autostart: ON + Battery saver: No restrictions.

Option B: Optional ADB Setup

Install and whitelist Hyper120 from Doze/background limits in one command block:

adb install -r Hyper120.apk
adb shell dumpsys deviceidle whitelist +com.custom.game120hz
adb shell appops set com.custom.game120hz RUN_ANY_IN_BACKGROUND allow
